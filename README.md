## 📝 Часть 1. Ручное тестирование (Manual QA)

В рамках первой части дипломного проекта был проверен полный цикл ручного тестирования веб-интерфейса и мобильного приложения. Работа велась на основе анализа технических требований и дизайн-макетов.

### 🎯 Что было сделано:
* **Анализ требований и макетов:** Провела полный аудит ТЗ и макетов в Figma для веб- и мобильной версий приложения, выявила и зафиксировала серые зоны в требованиях.
* **Проектирование тест-дизайна (Веб):**
  * Составила подробный чек-лист для проверки функциональности экрана «Статус заказа».
  * Спроектировала таблицы валидации полей для формы «Сделать заказ» с применением техник эквивалентного разделения и анализа граничных значений.
* **Разработка тест-кейсов (Мобильное приложение):** Разработала комплект функциональных тест-кейсов и проверок на вёрстку (UI/UX) для критически важного бизнес-функционала приложения.
* **Тестирование и дефект-менеджмент:** Провела сквозное (E2E) тестирование логики и вёрстки. Все обнаруженные дефекты оформила в виде профессиональных баг-репортов (с подробными Steps to Reproduce, Severity, Priority, Actual/Expected Result).
